# PixView

画像を「本」という単位でまとめて整理し、読むための画像ビューアです。

> 現在は開発初期の段階で、まだ動作するものはありません。
> この文書は、目指す姿と最初のリリースの範囲をまとめたものです。

## 目的

大量の画像を、ファイルやフォルダの配置ではなく、本と本棚という見方で整理して読めるようにします。

## 主な機能

### 本

- ひとかたまりの画像を 1 冊の本として管理します。
- 次の形式を本として扱えます。
  - 画像ファイルが入ったフォルダ
  - ZIP / CBZ
  - PDF
- 対応する画像の形式は、JPEG と PNG です。
- 本には作者を付けて整理できます。作者は、1 冊につき 1 人です。
- 本の元になるファイルは動かしません。アプリは、ファイルの場所だけを記録します。
- 本の数に上限は設けません。
- 本の元になるファイルは、端末内のストレージと NAS のどちらにも置けます。

### 読み方

次の読み方を選べます。

- 1 ページずつめくる。
- 見開きで表示する（右綴じ）。
- 縦にスクロールして読む。

### 本棚

- すべての本を、表紙つきの一覧で見られます。
- 作者別の本棚で、同じ作者の本をまとめて見られます。

### 並べ替え

- 最近読んだ順に並べ替えられます。
- 最近追加した順に並べ替えられます。

## 対応 OS

| OS | 対応時期 |
|---|---|
| Windows | 最初のリリース |
| Android | 最初のリリース |
| iOS | 後のリリース |

## 使用する技術

- UI フレームワーク：.NET MAUI（11.0.10 以降）
- 画像の描画：SkiaSharp

### 選んだ理由

- Windows、Android、iOS を 1 つのコードで対象にできます。
- 捨てる前提の試作を Windows と Android で動かし、次の点を確かめました。
  - 表紙を格子状に並べた本棚は、10 万冊でも冊数に関係なく安定してスクロールできました。
  - SkiaSharp による自前の描画で、8000x12000 の画像でも拡大縮小と移動が十分な速さで動きました。
  - Windows でのキー操作、ホイール操作、全画面表示は、Windows 用のコードを個別に書くことで実現できます。

Android の確認はエミュレーターで行っており、実機での確認はまだです。

## 最初のリリースの範囲

- Windows 版と Android 版を提供します。
- 上記の「主な機能」に挙げたものを対象とします。
- 本棚の内容は各デバイスで独立して管理します。

作業は [issue](https://github.com/aetos382/PixView/issues) に分けて進めています。

## 今後の対応を予定しているもの

- iOS 版
- デバイス間での本棚の同期

デバイス間の同期は最初のリリースには含めませんが、後から追加できるように、データの持ち方をあらかじめ配慮します。

## 後のリリースで検討するもの

- タグ（本へのタグ付けと、タグ別の本棚）
- ファイル名からの題名と作者の推定
- 読みかけの位置の記憶
- 検索
- 自分で作る本棚
- JPEG と PNG 以外の画像の形式

## 現時点では予定していないもの

- RAR や 7z など、ZIP 以外のアーカイブ形式への対応

## ビルドとテスト

.NET SDK 11.0.100 以降と、.NET MAUI のワークロード（Android、Windows）が必要です。
リポジトリのルートで次のコマンドを実行します。

```powershell
# ワークロードの導入（初回のみ）
dotnet workload restore

# ビルド
dotnet build

# テスト
dotnet test -f net11.0

# Windows 版の起動
dotnet run --project src/PixView -f net11.0-windows10.0.19041.0
```
